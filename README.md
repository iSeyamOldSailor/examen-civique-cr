# Examen civique CR

Application statique de préparation à la carte de résident. Les données de progression restent dans le navigateur. Le menu Sauvegarde permet de les exporter ou de les restaurer au format JSON de la version 3.

## Publication

GitHub Pages sert la racine de la branche main. Pour publier une mise à jour, modifier les fichiers concernés et le numéro RELEASE dans sw.js dans le même commit. Mettre à jour ASSETS si un fichier est ajouté. Conserver le chemin de publication, les identifiants de questions et les clés de stockage pour préserver la progression.

Une version déjà ouverte reste utilisable pendant une mise à jour. La nouvelle version prend le relais après la fermeture des fenêtres de l’ancienne version.
